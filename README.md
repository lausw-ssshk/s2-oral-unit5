# S2 Oral · Unit 5 — Starting & Ending a Presentation

Teaching materials for S2 Hong Kong ESL (booklet pp.14–15): openings A–D, ending in 3 steps, useful phrases, mini practice, and a short quiz.

**Teacher:** Sherlock Lau (`lausw-ssshk`)

## Open locally

Open `index.html` in a browser, or from this folder:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080/`.

## Files

| File | Purpose |
|------|---------|
| `index.html` | Hub — links to slides and quiz |
| `slides.html` | Full-viewport slide deck (keyboard ←/→ / Space, swipe, Prev/Next) |
| `quiz.html` | Interactive quiz (~12 items, shuffled; score + local timestamp only) |

No build step. No external CDNs. System fonts only.
