# S2 Oral · Unit 5 — Starting & Ending a Presentation

S2 Hong Kong ESL materials (booklet pp.14–15): how to start and finish a short talk.

**Teacher:** Sherlock Lau (`lausw-ssshk`)

## Open locally

Open `index.html` in a browser, or:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080/`.

## Files

| File | Purpose |
|------|---------|
| `index.html` | Hub — links to slides and quiz |
| `slides.html` | Slide deck (←/→ / Space, swipe, Prev/Next) |
| `quiz.html` | Quiz (~12 items; score + Hong Kong timestamp only) |

No build step. No external CDNs. System fonts + emoji visuals.

## GitHub Pages

- Hub: https://lausw-ssshk.github.io/s2-oral-unit5/
- Slides: https://lausw-ssshk.github.io/s2-oral-unit5/slides.html

The quiz does **not** collect names or emails. End screen shows score and a local timestamp only.
